# Sound Arcade

## Description
Sound Arcade is an accessible audio-based game designed for players with visual impairments. The game uses stereo sound and simple audio cues to create an engaging gameplay experience. Players navigate menus and play games entirely through keyboard controls and audio feedback.

## Menu

### Navigation
- Space bar is the ok button.
- Up arrow selects the previous menu item.
- Down arrow selects the next menu item.
- Escape is the back button.

### Home (Screen)
- Choose Game
- Settings
- Credits

### Game Selection (Screen)
- List avaliable games

### Game Menu (Screen)
- Play
- Help (Explains the game and its objective.)
